# Web Portofolio M1A2
## Deskripsi
- Web Portofolio ini dibuat dengan tujuan agar aku punya web Portofolio. Di web ini ditampilkan beberapa skill yang ku miliki, Projek-projek yang sudah selesai maupun yang sedang dikerjakan, di web ini juga terdapat biodata diri juga sosial mediaku.
